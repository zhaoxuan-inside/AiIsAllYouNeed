# 内置字体 · iA Writer Fonts

来源：https://github.com/iaolo/iA-Fonts （官方开源仓库，OFL-1.1 许可，见同目录 LICENSE-*.md）

| 文件 | 用途 |
|------|------|
| iAWriterQuattroS-Regular.woff2 | 全站正文/标题（拉丁），中文回退系统黑体 |
| iAWriterQuattroS-Bold.woff2 | 标题与强调（700） |
| iAWriterQuattroS-Italic.woff2 | Markdown 斜体（em） |
| iAWriterMonoS-Regular.woff2 | 代码 / 年份 / 统计数字 |

- 「S」系列为 iA Writer 当前出货版本（2021 重间距版）。
- 下载于 2026-10-11，@font-face 声明见 `src/app/theme.css`。
- family 名沿用 `iA Writer Quattro` / `iA Writer Mono`，与 CSS 令牌一致。
