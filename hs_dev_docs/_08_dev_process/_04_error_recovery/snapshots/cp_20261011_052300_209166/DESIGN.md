# DESIGN.md — AI 知识星图（AiIsAllYouNeed）

> 视觉契约 · 实现任何 UI 前必读 · **风格 v3：纸墨文库（阅读优先）**
> 灵感参照：「一本精心排版的 AI 文集 / 豆瓣阅读的纸感页面」——暖纸底、墨蓝正文、衬线标题、领域色作书脊色条；星夜深色模式保留可切换。

## 0. 风格总原则（v3 变更）

历史：v1 星图（衬线+深底）→ v2 像素风（装饰过度，不利阅读，已退役）→ **v3 纸墨文库：一切为阅读服务**。

1. **阅读第一**：正文 16px / 行距 1.8-1.85 / 行长 ≤ 38em；正文用系统黑体（原生渲染零成本），标题用思源宋体（Noto Serif SC，fontsource 分包加载）。禁止装饰性字体（像素/手写/等宽正文）。
2. **纸墨双色**：纸墨（暖纸白底 #FAF8F2）为默认；星夜（深靛蓝 #0A0E1F）为可选深色。两主题共用同一套布局与组件，仅令牌不同。
3. **领域色是功能性标识**：只用于书脊色条、徽章、图谱节点、时间线色点；小号彩色文字必须经 `domainTextColor()`（向主题文字色混合 28%）保证对比度。禁止大面积彩色色块。
4. **深度靠细边**：卡片 1px 细边 + 极轻投影（0 4px 16px @10%）；禁止粗黑边、硬阴影、发光按钮。
5. **圆角温和**：卡片 8px、小件 4-6px；不再回到像素直角，也不做胶囊滥用。

## 1. Visual Theme & Atmosphere

深夜书桌上一册摊开的《AI 文集》：纸面微暖、墨色沉稳、章节前有领域色书脊条；图谱页像一张夹在书里的星图卡片——安静、清晰、翻页般的轻交互。唯一的戏剧性留给首页「纸上星图」主视觉（墨色星辰极淡地浮在纸面上），其余界面全部让位给文字。

## 2. Color Palette & Roles

### 纸墨（默认 · 日间阅读）

| 令牌 | Hex | 角色 |
|------|-----|------|
| `--void` | `#FAF8F2` | 页面底（暖纸白） |
| `--panel` | `#FFFFFF` | 卡片/面板 |
| `--panel-edge` | `#E6E1D4` | 1px 细边/分隔 |
| `--star` | `#1F2A52` | 主文字（墨蓝） |
| `--star-dim` | `#6B7290` | 次级文字 |
| `--gold` | `#B8862F` | 强调：链接、当前项、影响力（琥珀） |
| `--domain-mix-target` | `#1F2A52` | 领域色文字混合目标（压深） |

### 星夜（可选 · 深色）

底 `#0A0E1F` 深靛蓝 · 面板 `#141B33` · 边 `#232C4D` · 文字 `#E9EDF8` · 次级 `#98A2C3` · 金 `#E5B85C`；混合目标 `#E9EDF8`（提亮领域色文字）。

### 领域色环（功能性，6 色相，节点/徽章/书脊）

机器学习基础 `#5B8DEF` · 自然语言处理 `#3FBEA8` · 计算机视觉 `#E0705A` · 强化学习 `#9D7BE8` · 大模型与生成 `#E5B85C` · 数学与理论 `#D46A9E`

## 3. Typography Rules

| 角色 | 族 | 说明 |
|------|-----|------|
| 标题/章节 | `'Noto Serif SC', 'Songti SC', Georgia, serif` | 衬线标题 28-30px；只用于标题与 `.font-display` |
| 正文/UI | `-apple-system, 'PingFang SC', 'Microsoft YaHei', 'Noto Sans SC', sans-serif` | 系统栈，16px / 1.8 行距 |
| 年份/统计/代码 | `ui-monospace, 'SF Mono', Consolas, monospace` | 数字对齐 |

- 正文行长 ≤ 38em；段落间距 0.9em；Markdown 正文 `.prose-knowledge` 统一管理。
- 禁止：像素/手写体、整段衬线正文、<12px 文字、标题字间距装饰。

## 4. Component Stylings

- **卡片**：白面板、1px `--panel-edge` 细边、radius 8px、极轻投影；hover 边转领域色 40%（不上浮）。
- **按钮**：主按钮 = 墨蓝实底（`bg-star`）+ 纸色文字，hover 轻降透明度；次按钮 = 透明底 + 1px 边；radius 8px；按压 translateY(1px)。
- **输入/搜索**：面板底、聚焦边转 `--gold`；下拉 = 面板 + 轻投影。
- **导航**：桌面左侧栏（当前项左侧 2px 金色标记）；移动底部 Tab。
- **徽章**：领域徽章 = 领域色 12% 底 + `domainTextColor` 文字 + 圆点。
- **图谱节点**：圆点，领域色，半径=影响力；hover 允许轻微 glow；依赖边实线箭头、相关边虚线。

## 5. Layout Principles

- 8pt 间距阶梯；内容列 max-width 1120px；**阅读正文列 max-width 38em**（详情页居中）。
- 桌面 ≥1024px：顶栏 64px + 侧栏 220px + 主区；移动 <768px：顶栏 + 主区 + 底部 Tab 56px。
- 首页「纸上星图」占 55vh（星辰极淡，不与文字争夺），之后：统计条 → 领域卡 → 双列列表。

## 6. Depth & Elevation

纸面层次：底 `--void` → 面板 `--panel`（1px 细边 + 极轻投影）→ 浮层（面板 + 轻投影 + 遮罩 `--overlay`）。禁止硬阴影/厚边/重投影；仅图谱节点 hover 允许 glow。

## 7. Do's and Don'ts

**Do**：一切小号彩色文字走 `domainTextColor()`；领域色只作标识；空态给方向链接；年份/统计用等宽字；术语保留英文。
**Don't**：禁装饰字体回归（像素/手写）；禁粗黑边与硬阴影；禁大面积彩色块；禁每节 fade-up 入场（保留页面级一次 rise-in）；禁无数据编造统计。

## 8. Responsive Behavior

- 断点：768 / 1024 / 1440。
- 图谱页：移动端详情侧栏 → 底部抽屉；画布拖拽/缩放不变。
- 阅读优先：移动端正文 16px 起步、行距 1.8 不缩。
- 触控目标 ≥44px；Tauri 移动端与 Web 共用同一响应式行为。

## 9. Agent Prompt Guide

实现任何界面：先读本文件；暖纸底 + 墨蓝正文 + 衬线标题 + 领域色书脊条/徽章；阅读参数（16px/1.8/38em）不可为装饰让步；小号彩色文字必须 `domainTextColor()`；不确定查 §2 色表与 §7 禁区。
