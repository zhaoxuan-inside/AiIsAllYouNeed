# DESIGN.md — AI 知识星图（AiIsAllYouNeed）

> 视觉契约 · 实现任何 UI 前必读 · **风格 v4：iA 极简文库（对标 iA Writer 设计语言）**
> 参照：「iA Writer 的排版哲学」——一族字体、近单色、零装饰、发丝分隔线、单一强调蓝；内容即界面。

## 0. 风格总原则（v4 变更）

历史：v1 星图 → v2 像素（退役）→ v3 纸墨文库 → **v4 对标 iA Writer：把「无」做到极致，让文字成为唯一的界面**。

1. **一族字体**：全站只有 iA Writer Quattro（拉丁，OFL）+ 中文系统黑体回退；代码/年份用 iA Writer Mono。标题与正文同族同色，**只靠字号与字重分层**（v3 的衬线标题退役）。
2. **近单色**：白底（夜间 #1E1E1E）+ 墨黑 #1A1A1A + 两级灰（#6B6B6B / #9E9E9E）+ **唯一强调蓝 #0B93F6**（夜间 #4DA3FF）。领域彩色只允许出现在「功能性圆点/节点」上（徽章圆点、图谱节点、时间线色点、书脊条），**彩色文字一律退役**。
3. **零装饰**：无阴影、无渐变、无 glow、无底色块。层次只用 1px 发丝线 `#E4E4E1` 与留白表达。
4. **无卡片**：列表 = 发丝线分隔的行；详情页内容直接排在纸面上（分节用上下发丝线）；「卡片」概念从组件词汇表移除。
5. **近直角**：radius 2px（输入框/按钮），不再使用 8px 圆角。
6. **阅读参数不变**：正文 16px / 1.85 / ≤38em（继承 v3，不可为装饰让步）。
7. **文字最小化（简洁 first）**：界面只保留功能性文字——导航、标题、数据、操作动词；解释性副标题、双语冗余（nameEn）、操作说明句一律删除，必要提示下沉到 `title`/`aria-label`。

## 1. Visual Theme & Atmosphere

iA Writer 式的「写作台」：打开就是一页干净的纸，顶栏与侧栏退为发丝线勾出的极简框架；标题是加粗的同族字，领航信息全是灰阶小字，唯一的蓝出现在链接、当前项与影响力星标上——像纸上唯一的批注笔颜色。首页主视觉是一条极淡的细线星座（静态 SVG 线稿），安静得像页眉的花线。

## 2. Color Palette & Roles

### 纸面（默认 · 日间）

| 令牌 | Hex | 角色 |
|------|-----|------|
| `--void` | `#FFFFFF` | 页面底 |
| `--panel` | `#FFFFFF` | 面板（与底同色，靠发丝线区分） |
| `--panel-edge` | `#E4E4E1` | 1px 发丝线 |
| `--star` | `#1A1A1A` | 主文字（墨黑） |
| `--star-dim` | `#6B6B6B` | 次级文字 |
| `--star-faint` | `#9E9E9E` | 三级文字（元信息） |
| `--accent` | `#0B93F6` | 唯一强调：链接、当前项、影响力、主操作 |
| `--hover-wash` | `#F6F6F4` | 行 hover 底 |

### 夜间（可选）

底 `#1E1E1E` · 线 `#383838` · 文字 `#D6D6D6` · 次级 `#9E9E9E` · 三级 `#6B6B6B` · 强调 `#4DA3FF` · hover `#262626`。

### 领域色（仅功能性圆点/节点）

机器学习基础 `#5B8DEF` · 自然语言处理 `#3FBEA8` · 计算机视觉 `#E0705A` · 强化学习 `#9D7BE8` · 大模型与生成 `#E5B85C` · 数学与理论 `#D46A9E`——**只作点/线/节点填充，不作文字色**。

## 3. Typography Rules

| 角色 | 族 | 说明 |
|------|-----|------|
| 全站 | `'iA Writer Quattro', -apple-system, 'PingFang SC', 'Microsoft YaHei', sans-serif` | **官方字体已内置**（iaolo/iA-Fonts woff2 在 `src/assets/fonts/`，OFL）；标题=同族 700；正文 400 |
| 代码/年份/统计 | `'iA Writer Mono', ui-monospace, Consolas, monospace` | 官方 Mono S 已内置；数字对齐 |

- 层级：H1 30px/700 → H2 20px/700 → H3 16px/700；正文 16px/400/1.85；行长 ≤38em。
- 禁止：第二字体族（含衬线标题回归）、彩色正文文字、斜体、<12px、标题字距装饰。

## 4. Component Stylings

- **列表行**：上下发丝线分隔；hover 只变 `--hover-wash` 底色，不上浮不变边。
- **徽章**：1px 发丝边小方框 + 领域色圆点 + 灰字；无底色。
- **按钮**：主 = 墨黑实底白字（`bg-star text-void`）radius 2px；次 = 1px 发丝边；按压 opacity 0.8。
- **链接/当前项**：`--accent` 蓝；当前导航项 = 加粗墨字 + 左侧 2px 蓝标。
- **输入/搜索**：白底 1px 发丝边，聚焦边转蓝。
- **图谱**：无外框；圆点节点**尺寸=被依赖数（入度）**、**填充=K-Means 空间聚类**（确定性算法，5 档低饱和色板，见 `domain/clusters.ts`）；hover/选中邻域聚焦、标签按需；概览无箭头。领域彩色只保留在筛选 chips 与徽章圆点。

## 5. Layout Principles

- 8pt 间距阶梯；内容列 max-width 1120px；阅读正文列 ≤38em。
- 桌面 ≥1024px：顶栏 64px + 侧栏 220px + 主区；移动 <768px：顶栏 + 主区 + 底部 Tab。
- 首页：细线星座线稿 → 大标题 → 统计行（大数字+发丝分栏）→ 领域列表行 → 双列知识列表。装饰只此一处，其余全白。

## 6. Depth & Elevation

**没有投影**。层次 = 发丝线 + 留白 + 灰阶。搜索遮罩用纯色 `--overlay`。

## 7. Do's and Don'ts

**Do**：彩色只给功能点；文字层级只靠字重字号灰阶；空态用文字+链接；hover 只动底色；按压只动透明度。
**Don't**：禁阴影/渐变/圆角>4px；禁彩色文字回归；禁衬线/像素/手写字体；禁卡片底色块；禁每节入场动效。

## 8. Responsive Behavior

- 断点：768 / 1024 / 1440。
- 图谱页：移动端详情侧栏 → 底部抽屉；画布拖拽/缩放不变。
- 阅读优先：移动端正文 16px/1.85 不缩。
- 触控目标 ≥44px；Tauri 移动端与 Web 共用同一响应式行为。

## 9. Agent Prompt Guide

实现任何界面：先读本文件；一族字体 + 近单色 + 发丝线 + 单蓝强调 + 无卡片；想加装饰前先问「iA Writer 会不会这么做」（九成九是不会）；不确定查 §2 色表与 §7 禁区。
