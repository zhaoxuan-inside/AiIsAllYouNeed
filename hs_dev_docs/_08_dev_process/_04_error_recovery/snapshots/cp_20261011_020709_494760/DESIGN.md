# DESIGN.md — AI 知识星图（AiIsAllYouNeed）

> 视觉契约 · 实现任何 UI 前必读 · 灵感参照：天文台星图 / 学术编年史（如「巴黎天文台的手绘星图集 × 一本严谨的 AI 编年史」）

## 1. Visual Theme & Atmosphere

**知识即星空**：每个知识点是一颗星，领域是星色，依赖关系是星线，时间是轨道。整体气质是「深夜天文台里摊开的一册手绘星图集」——安静、精确、带一点古典学术的衬线温度；交互响应如转动望远镜（平滑、有阻尼）。唯一的戏剧性留给首页星域主视觉，其余界面保持克制。

## 2. Color Palette & Roles

### 深色（默认 · 星夜）

| 令牌 | Hex | 角色 |
|------|-----|------|
| `--void` | `#0A0E1F` | 页面底（深靛蓝，**禁纯黑**） |
| `--panel` | `#141B33` | 卡片/侧栏面板 |
| `--panel-edge` | `#232C4D` | 描边/分隔（1px 轨道线） |
| `--star` | `#E9EDF8` | 主文字（暖白星光） |
| `--star-dim` | `#98A2C3` | 次级文字 |
| `--gold` | `#E5B85C` | 唯一强调色：关键 CTA、当前项、高影响力星标（星光金） |

### 领域色环（功能性配色，6 色相，全主题通用）

| 领域 | Hex |
|------|-----|
| 机器学习基础 | `#5B8DEF` 蓝 |
| 自然语言处理 | `#3FBEA8` 青绿 |
| 计算机视觉 | `#E0705A` 珊瑚 |
| 强化学习 | `#9D7BE8` 紫 |
| 大模型与生成 | `#E5B85C` 金 |
| 数学与理论 | `#D46A9E` 玫红 |

### 亮色（日间阅读 · 纸面）

底 `#F7F4EE` 暖纸白 · 面板 `#FFFFFF` · 文字 `#1B2340` 墨蓝 · 次级 `#5A6285` · 描边 `#E3DFD4`；领域色加深 15%，金改深金 `#B98A2F`。

## 3. Typography Rules

| 角色 | 族 | 说明 |
|------|-----|------|
| 标题/年代数字 | `Georgia, "Noto Serif SC", "Source Han Serif SC", serif` | 学术编年感；只用于标题与大数字，禁止整段衬线 |
| 正文/UI | `-apple-system, "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif` | 系统栈，多端零加载 |
| 数据/代码/年份数字 | `ui-monospace, "SF Mono", Consolas, monospace` | 时间线年份、统计数字 |

- 标题层级：H1 28-32px 衬线 → H2 20px → H3 16px；行高 1.6，正文行长 ≤ 42em（中文）。
- 禁止：标题字母间距大写化处理、单词异色强调、<12px 文字。

## 4. Component Stylings

- **卡片**：`--panel` 底、1px `--panel-edge` 边、radius 10px；hover 边转领域色 30%、微微上浮 1px；**禁大阴影/渐变卡**。
- **按钮**：主按钮 `--gold` 实底 + `#0A0E1F` 文字；次按钮透明底 + 1px 边；radius 8px；按下 scale 0.98。
- **输入/搜索**：`--panel` 底、聚焦时边转 `--gold`；搜索下拉 = 面板浮层带 1px 轨道边。
- **导航**：桌面左侧栏（图标+文字，当前项左侧 2px 金色轨道线）；移动底部 Tab（5 项：首页/图谱/时间线/路线/档案）。
- **徽章**：领域徽章 = 领域色 12% 透明底 + 领域色文字 + 圆点；年份一律等宽字体。
- **图谱节点**：圆点，领域色，半径=重要性；hover 外圈泛光（唯一允许的 glow，仅节点 hover）；依赖边=实线箭头，相关边=虚线，均低透明度。

## 5. Layout Principles

- 8pt 间距阶梯（4/8/12/16/24/32/48/64）。
- 内容列 max-width 1120px 居中；详情正文列 max-width 42em。
- 桌面 ≥1024px：顶栏 64px + 侧栏 220px + 主区；移动 <768px：顶栏 + 主区 + 底部 Tab 56px。
- 首页星域主视觉占首屏 55vh，其余区块顺序：统计条 → 领域卡 → 双列列表。

## 6. Depth & Elevation

不用投影表达层级：用**色阶层级**——底 `--void` → 面板 `--panel` → 浮层（面板+1px 金色 10% 边+backdrop-blur 8px）。仅图谱节点 hover 与 toast 允许轻微 glow。

## 7. Do's and Don'ts

**Do**：领域色只作功能性编码（归属），不作装饰；年代/统计用等宽字；空态给「去图谱探索」方向链接；中英混排时英文术语保持原文不加翻译腔。
**Don't**：禁纯黑/纯白底；禁装饰渐变、彩虹按钮、卡片阴影墙；禁 ALL-CAPS eyebrow 与 `WORD — fragment` 拼接式标题；禁每节 fade-up 入场动效（页面级一次性编排即可）；禁在无数据时编造统计数字。

## 8. Responsive Behavior

- 断点：768 / 1024 / 1440。
- 图谱页：移动端详情侧栏 → 底部抽屉（上滑 60vh）；画布支持单指拖动/双指缩放。
- 时间线：移动端年份节点左移为 24px 窄轨。
- 触控目标 ≥44px；Tauri 移动端与 Web 共用同一响应式行为。

## 9. Agent Prompt Guide

实现任何界面：先读本文件；深靛蓝夜空 + 领域色环 + 衬线标题 + 星图隐喻；一处大胆（首页星域）其余安静；不确定时查 §2 色表与 §7 禁区，禁止引入表外新色相。
