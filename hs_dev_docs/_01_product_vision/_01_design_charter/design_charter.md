- **单一真实源**：项目根目录 [`/DESIGN.md`](../../../../DESIGN.md)（本文件是阶段 0 的**存档与决策索引**，不重复定义 tokens；实现一律以 `/DESIGN.md` 为准）
- **状态**：FROZEN（待开发者视觉签收）
- **日期**：2026-10-16

## 1. 具象参照物与物理隐喻

「**天文台的玻璃控制台**」——冷冽、通透、克制；玻璃外壳退后，让知识上前。**对标来源**：现代 macOS / iPadOS 的浮动玻璃层（材质与层次）、天文/科研数据可视化（星图氛围）——**已改编，非品牌克隆**。

**明确拒绝对标**：Web2.0 拟物玻璃（高光瓣、投影瓣）、赛博霓虹、iA Writer 纸面（旧 v4，退役）、廉价 SaaS 仪表盘。

## 2. 五人机交互核心决策（源自审讯 Q4）

| 决策 | 结论 | 理由 |
|---|---|---|
| 主题 | **日间 / 夜间双一等公民**，`[data-theme]` 切换，默认跟随系统 | 阅读场景横跨白天与夜间，双模式不是附加而是基线 |
| 材质 | **全站玻璃拟态**（外壳半透明毛玻璃）；阅读面用 `--glass-strong` 保 WCAG AA | 满足「近两年设计主流 + 玻璃」诉求，同时守住阅读清晰度 |
| 强调 | **单一强调色**（日 `#2F6BFF` / 夜 `#6E9BFF`），首屏 ≤3 处 | 深色/浅色玻璃上都需可辨识；避免彩色泛滥 |
| 披露 | **功能按需**（hover/focus/需要时浮现），文字最小化，图标替代文字 | 用户要求「所有功能只在必要时展示，避免影响阅读」 |
| 图标 | **自绘 SVG 图标族**（线 + 节点语汇），禁第三方图标库/emoji | 用户要求「不廉价、贴合项目调性重绘」 |

## 3. 与旧 v4 的差异（防品味漂移）

| 维度 | 旧 v4（iA Writer） | 新 v5（Aurora Glass） |
|---|---|---|
| 底 | 纯白纸面 | 叠极光光晕的画布 + 玻璃外壳 |
| 字体 | iA Writer Quattro/Mono | Inter + 系统中文黑体 + JetBrains Mono |
| 层次 | 发丝线 + 留白 | 玻璃不透明度 + 模糊阶梯 + 高光边 |
| 圆角 | 近直角 2px | `chip 999 / control 12 / panel 18 / overlay 24` |
| 主题 | 日/夜（次要） | 日/夜（一等公民） |
| 强调 | 蓝 `#0B93F6` | 蓝 `#2F6BFF` / `#6E9BFF` |

## 4. Anti-Slop 护栏（硬性）

- 禁紫粉万能渐变 / 赛博霓虹 glow / 每节 fade-up / 千篇一律图标三列卡片。
- 禁把正文压在低不透明玻璃上；禁低对比灰字作正文；正文对比度 ≥ 4.5:1。
- 禁第三方图标库、emoji 当图标、字体图标、彩色正文文字、>2 字族、标题字距装饰。
- 禁假数据、假证言、未证实合规口号；示例数据须为真实 AI 知识。

## 5. 与特性原型的关系

所有特性 PRD 与原型**显式声明** `Inherits: /DESIGN.md`；特性层只允许定义**局部特化**（如图谱页的 canvas 交互、详情页的阅读排版），**禁止**重新定义色彩、字体族或全局哲学。
