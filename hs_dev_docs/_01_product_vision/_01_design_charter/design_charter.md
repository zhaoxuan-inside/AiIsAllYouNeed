## 1. 具象参照物与物理隐喻

「**实验室里的琉璃标本柜**」——清晨是暖米的纸与清透的玻璃，入夜是深墨的底与微光的玻璃；知识像被安放在玻璃层之间。**对标来源**：现代 macOS / iOS 的液态玻璃材质（Liquid Glass）、天文/科研数据可视化（星图氛围）、编辑型知识出版物的**衬线阅读体**——**已改编，非品牌克隆**。

**明确拒绝对标**：Web2.0 拟物玻璃（高光瓣、投影瓣）、赛博霓虹、iA Writer 纸面（旧 v4，退役）、**v5 极光玻璃（被否，退役）**、廉价 SaaS 仪表盘。

## 2. 人机交互核心决策（源自审讯 Q4 + v6 重设计裁定）

| 决策 | 结论 | 理由 |
|---|---|---|
| 主题 | 日间 / 夜间双一等公民，`[data-theme]` 切换，默认跟随系统；**全站仅一个主题控件** | 阅读场景横跨昼夜；v5 出现"日夜开关重复"被否，v6 收敛为单一入口（三选一：跟随/日/夜） |
| 材质 | **高保真液态玻璃**：全站三级模糊（`14/22/32`）+ 光边（inset ring）+ 折射光泽；阅读面用 `--surface`（近不透明）保 WCAG AA | 满足「近两年设计主流 + 玻璃」诉求，同时消除 v5「玻璃过满 / 不够高级」 |
| 字体 | **四角色字体系统**：Display / Reading = 衬线，Text = 无衬线（Inter），Mono = 等宽 | v5 全站无衬线「缺辨识度」；衬线给「知识」以分量 |
| 色彩 | **暖纸 × 深墨**冷暖对位；强调色 = 琉璃青（日 `#0E7C7B` / 夜 `#5EEAD4`） | v5 通用蓝「缺记忆点」 |
| 披露 | 功能按需（hover / focus / 需要时浮现），文字最小化，图标替代文字 | 用户要求「所有功能只在必要时展示，避免影响阅读」 |
| 图标 | **自绘 SVG 图标族**（线 + 节点语汇），禁第三方图标库 / emoji | 用户要求「不廉价、贴合项目调性重绘」 |
| 唯一性 | 「单一呈现」铁律：一能力一控件、一信息一主呈现 | v5「部分功能重复」被否 |

## 3. 与旧代的差异（防品味漂移）

| 维度 | 旧 v4（iA Writer） | 旧 v5（极光玻璃 · 被否） | 新 v6（琉璃） |
|---|---|---|---|
| 底 | 纯白纸面 | 冷白 / 深空 + 极光光斑 | 暖米白 / 深墨 + 四团低饱和光晕 |
| 字体 | iA Writer Quattro/Mono | Inter + 系统黑体（全无衬线） | 衬线(Display/Reading) + Inter(Text) + Mono |
| 层次 | 发丝线 + 留白 | blur 12/20/28 + 1px 实边 | blur 14/22/32 + **光边(inset)** + 折射光泽 |
| 圆角 | 近直角 2px | chip/control12/panel18/overlay24 | chip/control10/panel16/overlay22（**同心圆角**） |
| 主题 | 日/夜（次要） | 日/夜（一等公民，双开关） | 日/夜（一等公民，**单入口**） |
| 强调 | 蓝 `#0B93F6` | 蓝 `#2F6BFF` / `#6E9BFF` | 琉璃青 `#0E7C7B` / `#5EEAD4` |
| 控件边 | 发丝线 | **1px 实描边（廉价）** | 无描边：光边 + 面 |

## 4. Anti-Slop 护栏（硬性）

- 禁紫粉万能渐变 / 赛博霓虹 glow / 每节 fade-up / 千篇一律图标三列卡片。
- 禁把正文压在低不透明玻璃上；禁低对比灰字作正文；正文对比度 ≥ 4.5:1。
- **禁给按钮 / 分页 / chip 画 `1px solid` 灰边**；禁大圆角通用所有层级；禁堆叠重投影制造「高级感」。
- 禁第三方图标库、emoji 当图标、字体图标、彩色正文文字、同角色混用字族、标题字距装饰。
- 禁假数据、假证言、未证实合规口号；示例数据须为真实 AI 知识。
- **禁同一能力出现两个控件、同一信息在多页重复主呈现**（v5 被否原因之一）。

## 5. 与特性原型的关系

所有特性 PRD 与原型**显式声明** `Inherits: /DESIGN.md`；特性层只允许定义**局部特化**（如图谱页的 canvas 交互、详情页的阅读排版），**禁止**重新定义色彩、字体族或全局哲学。
