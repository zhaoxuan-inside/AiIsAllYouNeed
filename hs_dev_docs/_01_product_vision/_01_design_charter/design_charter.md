## 1. 具象参照物与物理隐喻

「**深夜书桌 · 台灯下的星图册**」——你翻开一本《AI 知识星图册》，一盏台灯照着它；**日 / 夜 = 灯关 / 灯开**。**对标来源**：Apple 的液态玻璃质感（仅材质）、iA Writer 的布局哲学（克制 / 文字优先）——**均作为单一元素被改编进"台灯下的书"这一新世界观，非品牌克隆**。

**明确拒绝对标**：Web2.0 拟物玻璃、赛博霓虹、企业蓝 SaaS、通用力导向图、v5 极光玻璃、v6 琉璃·液态玻璃（整代退役）。

## 2. 设计哲学（W1，Q13 拍板，此后不换方向）

1. **玻璃有用途（GUP）**：玻璃只做三件事——**灯罩**（顶栏/浮层）、**透镜**（悬停/选中聚焦）、**展柜**（图谱画布/阅读大面板）；列表、卡片、chip 一律纸面 + 发丝线。
2. **台灯即光源**：顶部一盏台灯洒下暖光；夜间是主光源。禁止在别处再造光。
3. **星图册是母题**：图谱 = 星图册线条（细曲线 + 星点 + 纸感噪点）；每领域一个星座；首页 = 摊开的星图页。
4. **日/夜 = 灯关/灯开**，两套令牌同为基线；阅读用衬线（读书感）、近不透明展柜、WCAG AA。
5. **图标自绘 · 天文制图语汇**：罗盘/台灯/书/透镜/星/书签…；禁图标库、emoji、字体图标。

## 3. 与旧代的差异（防品味漂移）

| 维度 | 旧 v6（琉璃·液态玻璃，被否） | 新 v7（星图册·台灯下） |
|---|---|---|
| 世界观 | 玻璃展示柜 / 暖纸×冷青 | **台灯下的星图册**；日/夜=灯关/灯开 |
| 玻璃 | 全站三级玻璃外壳 | **仅灯罩/透镜/展柜**；其余纸面+发丝线 |
| 字体 | 衬线 Display + Inter | **粗重黑体标题（Space Grotesk）** + Inter + 衬线只给读书 |
| 色彩 | 暖米白 + 琉璃青 | 台灯暖白纸 + **琥珀/暖金**强调 |
| 图形 | 通用力导向图 | **星图册线条 + 星点星座** |
| 签名 | 液态玻璃高光 | **顶部台灯光 + 透镜聚焦 + 星图册** |

## 4. Anti-Slop 护栏（硬性）

- 禁全站贴玻璃、每节 fade-up、紫粉渐变、霓虹、`1px solid` 实描边控件、图标库/emoji 当图标。
- 禁在别处再造"光"（台灯是唯一光源）；禁力导向动画堆料；禁中文首字下沉；禁假数据。
- 禁同一能力两个控件、同一信息多页重复主呈现（功能唯一性铁律）。

## 5. 与特性原型的关系

所有特性 PRD 与原型显式声明 `Inherits: /DESIGN.md`；特性层只允许局部特化（图谱页交互、详情页阅读排版），禁止重定义色彩、字体族或哲学。
