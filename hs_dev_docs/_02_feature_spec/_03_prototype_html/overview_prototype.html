Transformer

别名：Transformer 模型 · Attention Is All You Need
大模型与生成 2017 ★★★★☆ 难度 · 高 ~45 min #注意力#Seq2Seq

一种完全基于 注意力机制 的序列到序列架构，抛弃了 循环神经网络 的循环结构，使训练可以充分并行化。

Attention(Q, K, V) = softmax( QKᵀ / √d_k ) · V

它把序列建模从「逐步递归」改写为「全局加权」，成为此后所有 大语言模型 的骨架。
