## 1. 特性洞察与核心价值界定 (Framing & Discovery)

- **现状与摩擦**：想收藏/记笔记就得注册登录；而多数学习者只想本地随手记，不希望上传数据。
- **用户雇佣任务 (JTBD)**：`When` 我读到有价值的（或想稍后读的）知识点，`I want to` 直接收藏、标记已读、写一句笔记，`so I can` 下次快速找回，且**数据不出本机**。
- **惊喜时刻**：第一次点收藏时**即用即建**档案（轻量浮层，无需注册），之后状态自动保留。
- **冷启动**：未建档案时点收藏 → 弹出轻量建档浮层（昵称 + 选色），可跳过（用默认档案）。

---

## 2. 交互形态比选与取舍 (Approaches & Trade-offs)

| 维度 | 方案 A（推荐） | 方案 B（弃用） | 取舍理由 |
|---|---|---|---|
| **建档方式** | 即用即建轻量浮层（可跳过，落默认档案） | 强制先注册才可用 | 强制注册是反目标；即用即建降低摩擦且满足隐私 |
| **存储** | 浏览器本地持久化（localStorage/IndexedDB） | 服务器账号 | v1 无后端；本地足够且隐私友好 |
| **入口** | 顶栏头像 + 底部 Tab | 侧栏菜单项 | 与全站导航一致 |

## 3. 详细字段与业务规则约束矩阵 (Specifications & Constraints)

| 区块 | 内容 | 规则 |
|---|---|---|
| 档案头 | 头像色块 + 昵称（可改）+「数据仅存本机」提示 | 昵称 1–20 字；头像色从预设色板选 |
| Tab | 我的收藏 · 阅读进度 · 我的笔记 | 切换不丢状态 |
| 列表 | 收藏/已读/笔记对应知识点列表 | 点击进入详情；空态引导去图谱/时间线探索 |
| 笔记 | 针对知识点的一句话/短记 | 长度上限（如 2000 字）；随知识点存储 |
| 隐私 | 无网络上传 | 所有读写仅本机；无账号 |

### 业务分支规则矩阵
1. **已建档案**：直接读写。
2. **未建档案**：点收藏 → 建档浮层；跳过则用默认档案（匿名）记录。
3. **隐私模式/存储不可用**：降级为内存态（本次会话有效），并提示。

## 4. 需求原子分解与行为驱动验收标准 (Requirements & Functional DoD)

### 4.1 原子需求

| 需求编号 | 简述 | 关联动作 | 验收证据 | 优先级 |
|---|---|---|---|---|
| `REQ-001` | 即用即建档案（可跳过） | 首次收藏/打开档案 | 浮层建档；跳过可落默认档案 | P0 |
| `REQ-002` | 收藏/取消收藏并持久化 | 点击收藏 | 刷新后状态保留 | P0 |
| `REQ-003` | 阅读进度标记与展示 | 打开详情/标记 | 进度列表与状态一致 | P0 |
| `REQ-004` | 笔记增改删并随知识点持久化 | 编辑笔记 | 刷新后笔记存在 | P0 |
| `REQ-005` | 无网络上传 | 全程 | 无外部网络请求（走查/代码审查） | P0 |
| `REQ-006` | 空态引导 | 无收藏/笔记 | 展示引导去探索 | P1 |

### 4.2 Gherkin

```gherkin
Feature: 本地档案

  Scenario: REQ-001 首次收藏即用即建
    Given 访客尚无本地档案
    When 访客在某知识点点击「收藏」
    Then 弹出轻量建档浮层；建档或跳过后收藏被记录且可持久化

  Scenario: REQ-002/004 状态与笔记持久化
    Given 访客已建档
    When 访客收藏 A、标记已读并写笔记，随后重新打开应用
    Then 收藏、已读、笔记均保留在本机

  Scenario: REQ-005 隐私保证
    Given 访客使用全部个人化功能
    When 观察网络
    Then 无任何用户数据上传请求（仅加载本地资源）
```
