## 1. 特性洞察与核心价值界定 (Framing & Discovery)

- **现状与摩擦**：概念之间的**依赖关系**（先学什么、由什么演化而来）最难从列表/文档中获得；线性文章无法表达网络结构。
- **用户雇佣任务 (JTBD)**：`When` 我想理解某概念的前置与被依赖关系，`I want to` 在一张可缩放/漫游的图上看到节点与依赖边，`so I can` 规划学习路径与理解演化脉络。
- **惊喜时刻**：点击一个节点，邻域聚焦 + 详情抽屉即时滑出，脉络一目了然。
- **冷启动**：图谱由数据生成；筛选后为空的画布展示引导与重置。

---

## 2. 交互形态比选与取舍 (Approaches & Trade-offs)

| 维度 | 方案 A（推荐） | 方案 B（弃用） | 取舍理由 |
|---|---|---|---|
| **主交互** | **画布 + 右侧/底部详情抽屉**（主从式） | 点节点跳转到独立详情页 | 保持图上下文不丢失，适合连续漫游 |
| **渲染** | SVG 自绘（百级节点） | Canvas 位图 | SVG 可访问、可被 CSS/主题着色、布局纯函数可测；百级节点性能足够 |
| **节点语义** | 尺寸=入度、填充=空间聚类档位、领域色仅在筛选 chip/徽章 | 尺寸=重要性、颜色=领域 | 让「被依赖程度」与「聚类结构」直接可读；避免彩色泛滥 |

## 3. 详细字段与业务规则约束矩阵 (Specifications & Constraints)

| 元素 | 规则 |
|---|---|
| 节点 | 尺寸 = 入度（被依赖数）；填充 = 确定性 K-Means 空间聚类档位（5 档低饱和）；≥14 单位透明命中热区（移动可点） |
| 边 | 依赖边（prerequisites，实线）；相关边（related，虚线，可开关）；概览无箭头，聚焦显示方向 |
| 筛选 | 领域多选 chip（可带领域色圆点）；边类型开关 |
| 交互 | 拖拽/缩放画布；hover 聚焦邻域并显示标签；点击打开详情抽屉 |
| 抽屉 | ≥1024px 右侧玻璃栏；<1024px 玻璃底部抽屉（含安全区）；含「查看完整详情」 |
| 减动效 | `prefers-reduced-motion` 时布局静态（一次性计算），禁用仿真动画 |
| 空态 | 筛选后无节点：画布中央空态文案 + 重置筛选按钮 |

### 业务分支规则矩阵
1. 正常：渲染全部节点与边。
2. 筛选后为空：空态 + 重置。
3. 数据缺失依赖引用：构建期已拦截，运行时不应出现悬空边。

## 4. 需求原子分解与行为驱动验收标准 (Requirements & Functional DoD)

### 4.1 原子需求

| 需求编号 | 简述 | 关联动作 | 验收证据 | 优先级 |
|---|---|---|---|---|
| `REQ-001` | 渲染依赖图（节点=入度、边=依赖/相关） | 打开图谱 | 节点数与边数与数据一致；依赖边可区分 | P0 |
| `REQ-002` | 领域筛选 + 边类型切换 | 选择 chip/开关 | 画布节点与边按筛选更新 | P0 |
| `REQ-003` | 点节点打开详情抽屉并可跳完整详情 | 点击节点 | 抽屉内容与节点一致；可跳详情页 | P0 |
| `REQ-004` | 悬停邻域聚焦、标签按需 | hover 节点 | 邻域高亮、标签出现 | P1 |
| `REQ-005` | 空态重置 | 筛选后为空 | 空态 + 重置恢复 | P1 |

### 4.2 Gherkin

```gherkin
Feature: 知识图谱

  Scenario: REQ-001/003 漫游依赖网络并查看节点
    Given 知识数据含依赖关系
    When 访客打开图谱并点击某节点
    Then 节点尺寸反映入度、依赖边可区分，右侧（或底部）抽屉展示该知识点

  Scenario: REQ-002 按领域筛选
    Given 图谱已渲染
    When 访客选择「强化学习」chip
    Then 仅显示该领域节点（或其余降噪），依赖边同步更新

  Scenario: REQ-005 筛选结果为空
    Given 组合筛选后无匹配节点
    When 画布更新完成
    Then 展示空态文案与「重置筛选」，点击后恢复全部节点
```
