## 1. 特性洞察与核心价值界定 (Framing & Discovery)

- **现状与摩擦**：传统词条是「死」的；相关概念之间没有跳转，读者需手动搜索，破坏阅读心流。
- **用户雇佣任务 (JTBD)**：`When` 我在读一个概念并遇到陌生概念，`I want to` 就地点击跳转到它、并在回看时看到「谁引用了我」，`so I can` 顺着知识网络自然深入而不迷失。
- **惊喜时刻**：正文里任意 `[[概念]]`、依赖/相关/论文/标签均可点击互达；底部「反向链接」把我引向被引用的上下文。
- **冷启动**：详情由数据生成；缺字段时优雅降级（不显示空区块）。

## 2. 交互形态比选与取舍 (Approaches & Trade-offs)

| 维度 | 方案 A（推荐） | 方案 B（弃用） | 取舍理由 |
|---|---|---|---|
| **跨链接方式** | 正文内 `[[知识点]]` 内联跳转 + 结构化字段跳转 + 反向链接区 | 仅底部「相关」列表 | 内联链接让阅读即探索，符合「知识网络」定位 |
| **阅读布局** | 单列阅读流（≤66ch），分节用留白 | 多栏/侧栏目录常驻 | 阅读优先；目录按需浮现（渐进披露） |

## 3. 详细字段与业务规则约束矩阵 (Specifications & Constraints)

| 字段/区块 | 披露层级 | 规则 |
|---|---|---|
| 标题 + 别名 | 首屏 | 别名可点击？否（仅展示）；标题为页锚点 |
| 一句话定义 | 首屏 | 大字摘要（引导句），可含链接 |
| 详细解读正文 | 首屏 | Markdown；支持 `[[知识点]]` 内联链接、公式（KaTeX/自绘）、图片/视频引用（`media`） |
| 元信息条 | 首屏 | 领域色点 + 年份 + 重要性 + 难度 + 学习时长 + 标签（均可点击筛选/跳转） |
| 关键论文 | 折叠/次屏 | 标题 + 作者 + 年份 + 会议 + 外链（新窗口）；论文可反向「被哪些知识点引用」 |
| 前置依赖 / 衍生发展 | 次屏 | 迷你依赖图 + 列表；点击跳转 |
| 相关知识点 | 次屏 | 列表/chips；点击跳转 |
| 反向链接 (backlinks) | 次屏 | 列出引用了本知识点的其它知识点（来自 WikiLink 与结构化字段） |
| 地方操作 | 首屏/悬浮 | 收藏、标记已读、记笔记（写入本地档案 FEAT-008），功能按需浮现 |
| 趋势标注 | 次屏 | 该知识点「发展方向」文本 |

### 业务分支规则矩阵
1. **字段存在**：渲染对应区块。
2. **字段缺失**：不渲染空区块（不显示「暂无」占位，除非整页无正文）。
3. **WikiLink 悬空**（指向不存在知识点）：构建期告警并降级为纯文本（不产生死链）。
4. **正文含媒体**：图片懒加载，公式服务端/构建期预渲染或运行时 KaTeX。

## 4. 需求原子分解与行为驱动验收标准 (Requirements & Functional DoD)

### 4.1 原子需求

| 需求编号 | 简述 | 关联动作 | 验收证据 | 优先级 |
|---|---|---|---|---|
| `REQ-001` | 渲染完整知识点（字段齐全时） | 打开详情 | 各区块与数据一致 | P0 |
| `REQ-002` | 正文 `[[知识点]]` 内联跳转 | 点击内联链接 | 跳转对应详情 | P0 |
| `REQ-003` | 结构化字段跳转（依赖/相关/标签/论文/领域） | 点击 | 分别跳详情/筛选/外链 | P0 |
| `REQ-004` | 反向链接展示 | 渲染 | 列出所有引用来源且可跳转 | P1 |
| `REQ-005` | 收藏/已读/笔记写入本地档案 | 操作本地 | 刷新后状态保留 | P0 |
| `REQ-006` | 字段缺失优雅降级 | 数据缺字段 | 不渲染空区块，页面无破版 | P0 |

### 4.2 Gherkin

```gherkin
Feature: 知识点详情与交叉链接

  Scenario: REQ-001/002 阅读并顺链深入
    Given 知识点 A 正文含 [[知识点 B]]
    When 访客打开 A 并点击 B 链接
    Then 进入 B 的详情，且 B 的「反向链接」列出 A

  Scenario: REQ-005 本地状态持久化
    Given 访客已建立本地档案
    When 访客收藏 A 并标记已读，然后刷新页面
    Then A 的收藏与已读状态保留

  Scenario: REQ-006 字段缺失降级
    Given 知识点 C 无「关键论文」与「趋势」字段
    When 打开 C 详情
    Then 不渲染论文与趋势区块，页面无空占位破版
```
