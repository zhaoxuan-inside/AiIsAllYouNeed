## 1. 特性洞察与核心价值界定 (Framing & Discovery)

- **现状与摩擦 (Status Quo)**：AI 知识散落在论文、博客、课程与收藏夹中，缺少一张「全局地图」；新学习者不知道从何入手，老手找不到概念之间的依赖脉络。
- **用户雇佣任务 (JTBD)**：`When` 我想了解 AI 领域的全貌或不确定从哪个概念开始，`I want to` 一眼看到知识总量、领域分布与最值得先读的知识点，`so I can` 决定下一步深入方向。
- **惊喜时刻 (Aha Moment)**：进入首页 3 步内——星图亮起 → 统计行给出规模 → 点击领域圆点即进入该领域，感知「这是一张可漫游的活知识网络」。
- **冷启动体验 (FTUE)**：MVP 首屏**永不为空**（内容随构建打包）；若数据异常为空，展示引导文案 + 指向「图谱 / 搜索」的入口。

## 2. 交互形态比选与取舍 (Approaches & Trade-offs)

| 评估维度 | 方案 A（推荐采纳） | 方案 B（备选弃用） | 取舍理由 (Trade-off Rationale) |
|---|---|---|---|
| **首页形态** | **单列文字流**：星图主视觉 → 等宽统计行 → 领域入口行 → 单列最新/重要知识流 | 仪表盘式双列卡片矩阵 | 单列保证 F 型扫视动线顺畅、阅读优先；双列易碎成「卡片墙」，违背简洁与玻璃阅读护栏 |
| **主视觉** | 自绘 SVG 星图（可漫游，五彩点为领域入口） | 静态大图 / 无主视觉 | 星图是产品名的直译与差异化；可交互才配得上「星图」，但保持轻盈（一次入场、无鼠标耦合） |
| **统计呈现** | 等宽 digit 的一行轻量统计（知识点/领域/论文/年份跨度） | 大号数据卡片 | 统计是辅助元信息，不应抢主视觉；等宽对齐降低噪音 |

## 3. 详细字段与业务规则约束矩阵 (Specifications & Constraints)

| 区块 | 披露层级 | 内容 | 规则 / 边界 |
|---|---|---|---|
| 星图主视觉 | 首屏 | 自绘 SVG：领域彩点 + 墨点织网 | 彩点可 hover 浮出领域名、点击进入领域页；`prefers-reduced-motion` 时静止；无数据时隐藏并让位空态 |
| 统计行 | 首屏 | 知识点数 · 领域数 · 论文数 · 年份跨度 | 数字 `tabular-nums`；年份跨度用「最早—最晚」；数据为空显示 `—` |
| 领域入口 | 首屏 | 领域列表行（色点 + 名称 + 知识点数） | 每领域一行，≤ 8 领域；点击进入领域页；领域色仅作圆点 |
| 最新知识流 | 首屏 | 单列：最新收录（按 `year`/收录序） | 默认 6 条 + 「查看全部」；每行 = 标题 + 一句话定义 + 领域色点 + 年份 |
| 重要知识流 | 首屏 | 单列：高影响力（`importance` 排序） | 默认 5 条；可切 tab 与最新互斥 |
| 快速搜索入口 | 首屏 | 顶栏搜索（**全站唯一搜索入口**，⌘K） | 触发全局搜索（FEAT-006）；**不再另设「星图下方提示行」**（单一呈现铁律）；首屏强调色 ≤ 3 处 |

### 业务分支规则矩阵
1. **有数据**：按上表渲染；星图动效一次入场。
2. **数据为空/异常**：隐藏星图，展示空态文案 + 「前往图谱」「打开搜索」两个入口。
3. **领域超过 6 个**：星图色点按扩展色板 `domain/N`，统计与入口行同步扩展。

## 4. 需求原子分解与行为驱动验收标准 (Requirements & Functional DoD)

### 4.1 核心需求原子分解清单 (Atomic Requirements Matrix)

| 需求编号 | 需求名称与规则简述 | 关联字段/动作 | 验收物理证据 | 优先级 |
|---|---|---|---|---|
| `REQ-001` | 首屏展示知识规模统计 | 渲染统计行 | 统计数字与数据仓库一致（知识点/领域/论文/年份跨度） | P0 |
| `REQ-002` | 领域入口可进入领域页 | 点击领域行/星图彩点 | 路由跳转至领域页且领域上下文正确 | P0 |
| `REQ-003` | 最新/重要知识流可进入详情 | 点击知识行 | 路由跳转至对应知识点详情 | P0 |
| `REQ-004` | 星图主视觉可漫游且减动效静止 | hover/click、`prefers-reduced-motion` | 彩点 hover 显示领域名；减动效时无动画 | P1 |
| `REQ-005` | 空数据冷启动引导 | 数据为空 | 展示空态与「图谱/搜索」入口，无死胡同 | P0 |

### 4.2 行为驱动产品验收场景 (Gherkin Scenarios)

```gherkin
Feature: 首页全景

  Scenario: REQ-001/002/003 冷启动浏览并进入知识点 (Happy Path)
    Given 应用已加载完整知识数据
    When 访客打开首页
    Then 首屏展示统计行、领域入口与知识流，任一领域 2 次点击内可到达知识点详情

  Scenario: REQ-002 从星图彩点进入领域
    Given 首页星图已渲染领域彩点
    When 访客悬停并点击某领域彩点
    Then 浮出领域名并跳转至该领域页，其筛选上下文与彩点一致

  Scenario: REQ-004 系统减动效
    Given 系统开启 prefers-reduced-motion
    When 访客打开首页
    Then 星图不做入场/呼吸动画，彩点仍可 hover 与点击

  Scenario: REQ-005 数据为空冷启动
    Given 知识数据为空或加载异常
    When 访客打开首页
    Then 隐藏星图，展示空态文案与「前往图谱」「打开搜索」入口
```
