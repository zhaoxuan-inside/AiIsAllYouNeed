## 3. 四态 / 规则

| 态 | 表现 |
|---|---|
| 未设置 | 跟随系统（首屏前内联注入，无闪烁） |
| 已设置 | 覆盖并持久化 |
| 系统变化且「跟随」 | 实时切换 |
| 异常（存储不可用） | 会话内存态，提示不阻断 |

**对比度护栏**：两主题正文有效对比度 ≥ 4.5:1（玻璃合成后）。
