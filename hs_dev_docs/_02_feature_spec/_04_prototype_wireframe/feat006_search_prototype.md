## 3. 空查询 / 无结果 / 四态

```text
空查询:                        无结果:
+----------------------+       +----------------------+
| 🔍 输入以搜索……      |       | 🔍 zzzz              |
| 推荐: Transformer    |       | 未找到相关知识点      |
|      注意力机制      |       | 试试: Transformer     |
| 最近: 反向传播       |       |       注意力机制      |
+----------------------+       +----------------------+
```
| 态 | 表现 |
|---|---|
| 正常 | 命中高亮 |
| 空查询 | 推荐词 + 最近搜索（本机） |
| 无结果 | 「未找到」+ 推荐词 |
| 异常 | 「搜索索引不可用」+ 提示重开应用 |
