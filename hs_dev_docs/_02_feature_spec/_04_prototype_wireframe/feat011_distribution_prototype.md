## 3. 四态 / 平台规则

| 项 | 规则 |
|---|---|
| 正常 | 各端同一套断点 640/1024 与主题 |
| 离线 | 数据内嵌，断网完整可浏览 |
| 触控 | ≥44px；移动顶栏/底栏/抽屉用 `env(safe-area-inset-*)` |
| 构建 | Web 必达；桌面/移动按平台工具链执行，交付配置+文档 |
