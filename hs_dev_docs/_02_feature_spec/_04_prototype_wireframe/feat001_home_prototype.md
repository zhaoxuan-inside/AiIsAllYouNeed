## 4. 四态

| 态 | 表现 |
|---|---|
| 正常 | 上表 |
| 空白/异常空 | 隐藏星图；文案「知识数据暂不可用」+ [前往图谱] ★ / [打开搜索] |
| 加载 | 星图占位虚线 + 标题/统计/列表 1:1 骨架脉冲（CLS=0） |
| 异常 | 同「空白/异常空」，保留顶栏，主 CTA 为 [重新加载] |
