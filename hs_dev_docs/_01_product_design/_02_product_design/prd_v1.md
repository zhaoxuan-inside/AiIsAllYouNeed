# PRD — AiIsAllYouNeed · AI 知识星图 v1

> change_size=L · work_mode=DESIGN→IMPLEMENT · 冻结日期：2026-10-11
> 状态：**已冻结**（审讯 4 题闭合 + 假设标注，见 §7）

## 1. 一句话定位

以「知识点」为核心单元，美观优雅地展示 AI 领域知识全景：知识脉络、发展时间线、领域发展路线、知识点依赖关系、发展趋势预测；知识数据经 Git 仓库更新；一套代码覆盖 Web / Windows / Linux / macOS / iOS / Android 六端。

## 2. 为谁 / 成功与失败

- **目标用户**：AI 学习者、研究者、工程师、爱好者（中文为主）。
- **成功**：新访客 10 秒内能看懂「AI 知识全景图」并找到感兴趣的知识点；一次搜索 3 秒内定位知识点；图谱/时间线/路线/依赖四种视图一致、互达。
- **失败（反目标）**：变成论文搜索引擎（论文只是知识点的引用）；变成需要注册才能看的封闭社区；知识点之间无关联的孤立卡片堆。

## 3. 核心概念模型（冻结）

| 概念 | 定义 |
|------|------|
| **知识点 KnowledgePoint** | 展示核心单元：一个 AI 概念/技术/模型/思想（如 Transformer、CNN、Attention）。含一句话定义、详细解读、提出年份、重要性、关键论文引用、前置依赖、衍生发展、相关知识点、趋势标注 |
| **领域 Category** | 知识点的顶层分类（如 机器学习基础、NLP、CV、强化学习、大模型），有主题色，是图谱着色/筛选维度 |
| **论文 Paper** | 知识点的支撑引用材料（标题/作者/年份/会议/链接），**不是**展示主体 |
| **发展路线 Roadmap** | 一个领域内知识点的阶段化学习/演化路径，由依赖关系拓扑排序 + 编辑分阶段（基础→进阶→前沿）生成 |
| **趋势标注 Trend** | 编辑整理的发展方向洞察：领域级趋势页 + 知识点级「发展方向」字段（**v1 无算法预测**，见假设 A3） |
| **本地档案 Profile** | 用户系统信息只存本地：昵称、收藏、阅读进度、笔记；无注册登录、无服务器 |

## 4. 核心场景与 DoD（冻结）

| # | 场景 | DoD |
|---|------|-----|
| S1 | 全景浏览 | 首页展示统计概览 + 六大领域入口 + 最新/重要知识点；任一领域 2 次点击内可达知识点详情 |
| S2 | 知识图谱 | 力导向依赖图：按领域着色、可按领域筛选、点击节点打开详情侧栏；依赖边（prerequisites）与相关边（related）可区分 |
| S3 | 时间线 | 按年份纵向时间线（1943→2026）展示知识点提出时间，可按领域筛选，点击进入详情 |
| S4 | 发展路线 | 每领域一条阶段化路线（基础→进阶→前沿），节点显示依赖顺序，可跳转详情 |
| S5 | 搜索 | 全局搜索框：标题/别名/摘要/标签中文可搜，结果 <100ms（客户端索引），高亮命中，可跳详情 |
| S6 | 知识点详情 | 定义、解读、关键论文、依赖关系小图（前置/衍生）、相关知识点、发展趋势；未读/已读状态 |
| S7 | 本地用户系统 | 游客可完整浏览；可创建本地档案（昵称+头像色）；收藏/进度/笔记仅存本地（localStorage/IndexedDB）；换端不同步（v1 明示） |
| S8 | 多端一致 | 同一代码库：Web（PWA-ready）+ Tauri 2 打包 Windows/Linux/macOS/iOS/Android；响应式布局适配桌面宽屏与移动窄屏 |

**非目标（v1）**：账号云同步、评论社区、论文全文托管、AI 问答、算法化趋势预测、自建更新服务器（v2 规划，数据格式需前向兼容）。

## 5. 数据与更新（冻结）

- 知识数据 = `knowledge/` 目录（纯数据仓库区）：知识点/领域/论文/路线/趋势的结构化数据（JSON + Markdown 叙述），**与应用代码分离**。
- v1 数据随应用打包构建；数据 schema 版本化，为 v2「自建服务器拉取更新」前向兼容。
- 更新流程：改 `knowledge/` → 提 Git → 重新构建/发版（v2 换成服务器拉取）。

## 6. 语言

界面与知识解读用中文；论文标题、作者、专有名词保留英文原文。

## 7. 假设与风险

| ID | 假设 | 风险/回退 |
|----|------|-----------|
| A1 | 内容单元=知识点，论文为引用 | 已由用户确认 |
| A2 | 6 端同时 = 一套 Web 代码 + Tauri 2 壳（唯一能同时覆盖桌面+移动的开源方案）；移动端构建验证依赖对应平台工具链，v1 交付可构建配置+文档 | 移动端真机构建若受阻 → 桌面+Web 先行，配置保留 |
| A3 | 「预测知识发展轨迹」v1 = 编辑整理的趋势标注（领域趋势 + 知识点发展方向字段） | 用户若期望算法预测 → v2 引入数据驱动 |
| A4 | 种子内容约 100 个知识点、6 个领域（自查默认） | 首屏单薄 → 后续内容扩充仅为数据添加 |
| A5 | 本地用户系统无加密需求（信息仅本地、非敏感凭据） | 后续云同步时再引入账号安全体系 |
