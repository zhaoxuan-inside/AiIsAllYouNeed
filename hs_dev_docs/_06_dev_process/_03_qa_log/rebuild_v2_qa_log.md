### Q10. 视觉二轮（v6 → v6.1）：液态玻璃加强 + iA 布局哲学

- **题域**：视觉细则
- **开发者裁定**：**仍不通过，继续改视觉**

- **对标参考**：**Apple 的液态玻璃 + iA Writer（ia.net/writer）的布局哲学**
- **采纳决策**：
  - 玻璃升级为**厚玻璃**：渐变填充 + `blur(200% saturate, brightness 1.10)` + 上缘高光 + 底部厚度 + 色散暗示 + **跟随光标的悬浮折射光泽**（页面另加一层全局"光标光"）。
  - 布局哲学对齐 **iA Writer**：框架克制、文字优先、**居中阅读列（≤68ch、内左对齐）**、大量留白；中文正文禁用首字下沉。
  - **图谱重做**：曲线边（依赖实线 / 相关虚线）+ 节点上缘高光 / 底部投影 / 悬浮光环与标签浮出 + 点阵网格（径向淡出）+ 左下角图例 + 右侧玻璃详情栏。
  - 数据规模：**Demo 少量数据即可**（足以看布局 / 字体 / 颜色），完整标题清单后续提供（不阻断设计冻结，亦不阻断阶段 1）。

### Q13. 设计哲学定稿：采用 W1「星图册·台灯下」

- **题域**：设计哲学（Design DNA 定稿）
- **开发者裁定**：在三个候选（天文台/出版物/精密仪器）中选「我另有世界观」；经协商后**采用 W1「星图册·台灯下」（Map Book under the Lamp）**，并**保留三项硬约束**：日/夜双主题、玻璃质感、自绘图标。
- **W1 要点（作为新哲学唯一依据）**：
  1. 世界观：深夜书桌前翻开《AI 知识星图册》，一盏台灯照着；**日/夜 = 灯关/灯开**。
  2. 玻璃只做三件有用途的事：**台灯灯罩**（顶栏/浮层柔光）、**透镜聚焦**（悬停/选中节点区域光学放大）、**展柜玻璃**（大内容面板）；**不再全站贴玻璃**。
  3. 图形：图谱改为**星图册线条**（细手绘感曲线 + 星点 + 轻微纸感噪点）；每领域一个星座。
  4. 字体：标题=粗重现代黑体（不强制衬线），正文=高可读黑体，数据=等宽。
  5. 色彩：日=台灯暖白纸 + 琥珀强调；夜=深墨书房 + **单一暖金（台灯色）**；领域=星座色。
  6. 图标：自绘「天文制图」语汇（罗盘/星点/透镜/书签/铅笔）。
  7. 签名体验：进入页面台灯缓缓点亮；悬停节点=透镜放大 + 柔光。
- **约束**：本方向定死后不再换；以「反例教训（Q12）」+ W1 七要点为新视觉的唯一准则。
- **关联落盘**：`/DESIGN.md`（将重写为 v7）、`overview_prototype.html`（将重写）、`rebuild_v2_plan.md`(S0-17)。
